# Game Engine

Description: There are two games inside this code, one being a basic Space Game and the other a Sprite Based Game

Features: The space game is RNG based. Every few seconds an asteroid and an enemy ship will spawn in random locations. You pilot a spaceship to avoid asteroids
	and shoot down the enemy ships. The sprite-based game is a simple platformer where you control the Hero and fight off monsters



Instructions: To play the game, run the Main.cpp file. Use the arrow keys to move your character and spacebar to shoot in the space game. 
			In the sprite-based game, use the arrow keys to move and jump, and use the attack key to fight monsters.

Known Issues: The Space Game works just fine last time it was tested, but the Sprite Game needs some work. The main issues I've found is enemies not spawning, broken gravity, and broken movement
